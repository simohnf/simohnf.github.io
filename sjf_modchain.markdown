*sjf_modchain* is a flexible semi-modular multi-effects engine. Featuring a suite of effect modules driven by freely assignable modulators.

---

<p align="center">
    <img width="500" alt="modchain1" src="/Images/modchain1.png" />
</p>


### Features
- Flexible Modulation Matrix: 6 multi-waveform LFOs and 2 dynamic Envelope Followers designed to be routed to any effect parameter across the plugin.
- 17+ FX Modules: A toolbox of spatial, dynamics, filter, and saturation processors—including Moog Ladder and SVF filters, bit-crushing, spectral manipulation, and stereo enhancement.
- Signal Architecture: Dedicated input/output gain staging, optional global oversampling for alias-free saturation, and a safety limiter at the end of the chain.

### Bug Reports and Feature Requests

*sjf_modchain* is an ongoing project, and as time passes I intend to add more features, modulators, and processors. 


If you find any bugs please report the to <support@sjfaudio.co.uk>.


You are welcome to request new features, but please keep in mind that not every request will be possible and even those that are may take time to implement. 


Please also consider [donating](https://simon-fay.kit.com/products/support) to help support development, if you have not already done so.

Source code is available on my [github](https://github.com/simohnf/sjf_modchain).
